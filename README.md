# CraveRush - Online Food Ordering System (tkinter + SQLite)
Run: `python app.py` (Python 3.8+, no extra packages; tkinter ships with Python).
Demo logins: customer cust@craverush.com / cust123 | restaurant spice@craverush.com / rest123 (or pizza@...) | admin admin@craverush.com / admin123
Flow: Login -> Menu -> Add to cart -> Place order -> Order page (Track simulation, View Bill).
